# Uppställningar

Träna uppställningar (algoritmer) i de fyra räknesätten, siffra för siffra: addition, subtraktion,
multiplikation och division (kort division, trappan, liggande stolen). Nya tal varje gång.

- `index.html` – sidan med spelet
- `uppstallning.js` – spelet
- `manifest.webmanifest` + `sw.js` – gör att sidan kan installeras som app och fungerar utan internet

Flyttat från Mattekompassen (mattekompassen/nikpet) 2026-11-26. Publiceras med GitHub Pages från grenen `main`.
